# SoloStore

A lightweight self-hosted file storage web app optimized for SoloHost, allowing users to easily upload, organize, preview, download, rename, and delete files directly on their own private server with zero external cloud dependencies.

## Features
- Drag-and-drop file upload with progress indicator
- Folder creation and hierarchical file organization
- Real-time search and instant filtering
- File preview, download, and deletion
- Storage usage summary and quota indicator dashboard
